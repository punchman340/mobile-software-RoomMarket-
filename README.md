## 1. 앱 기획 및 테마 설명
* **앱 이름:** RoomMarket
* **테마:** 한눈에 들어오는 직관적인 UI의 맞춤형 숙소 예약 플랫폼
* **기획 의도:**
  사용자가 복잡한 과정 없이 원하는 숙소를 쉽게 탐색하고, 즉각적으로 예약할 수 있는 숙소 마켓입니다. 기말고사 필수 요건인 뷰바인딩, recyclerview, navigationdrawer 등을 활용하여 설계했습니다. 단순히 목록만 보여주는 것이 아니라 최근 본 숙소 저장를 기록하는 기능과 예약 목록을 통해 실제 상용 앱과 유사한 흐름을 구현하고자 했습니다.


## 2. 개발 및 실행 환경

* **IDE:** Android Studio
* **Language:** Kotlin
* **Min SDK:** 26
* **Target SDK:** 36

## 3. 주요 액티비티(Activity) 및 XML 구성

본 앱은 기능별로 클래스와 레이아웃이 분리해 놨으며, 기말고사 요건을 모두 충족하도록 설계했습니다.

### [인트로 및 메인 허브]
* **`SplashActivity`:** 앱 실행 시 나타나는 스플래시 화면. 이용해 2.5초 대기 후 메인 화면으로 자동 전환됩니다.
* **`MainActivity`:** 네비게이션 드로어와 툴바 옵션 메뉴를 지원하는 메인 화면.


### [숙소 목록 및 예약 기능]
* **`ListActivity`:** RecyclerView와 RoomAdapter, RoomRepository 데이터를 이용한 숙소 목록 화면입니다.
* **`DetailActivity`:** 선택한 숙소의 상세 정보(이미지, 가격, 설명) 확인 및 예약 처리를 하는 숙소 상세 화면입니다.
* **예약 다이얼로그 & 스낵바:** 숙소 예약 버튼 클릭 시 AlertDialog로 확인창이 뜨며, 승인 시 하단에 SnackBar로 예약 완료 표시가 뜹니다.

### [마이페이지 및 예약 내역]
* **`MyPageActivity`:** '최근 본 숙소' 내역을 텍스트로 불러와 띄워줍니다.
* **`ReservationListActivity`:** 예약이 완료된 숙소 내역을 불러와 리스트 형태로 확인하는 예약 내역 목록입니다.


## 4. 앱 실행 및 조작 방법

1. 압축을 푼 폴더를 Android Studio에서 열고.
2. 하단 상태 표시줄에서 Gradle Sync 후,
3. 매니페스트 파일에 `SplashActivity`가 첫 시작 부분으로 설정되어 있습니다. 그 곳에서 실행을 하고,
4. 2.5초 후 메인 화면에 진입하면 화면 중앙의 버튼을 누르거나, 왼쪽 상단의 줄 세개 메뉴 아이콘을 통해 네비게이션 드로어를 열 수 있습니다.
5. 드로어 메뉴나 버튼을 통해 숙소 목록 화면으로 이동한 뒤, 카드를 클릭하여 상세 페이지를 확인하고 예약 기능을 테스트할 수 있습니다.


## 5. 참고 사항
**Parcelize 활용:** 객체를 통째로 안전하게 넘기기 위해 `@Parcelize` 플러그인을 적용
**데이터 저장:** 서버나 DB를 쓰지 않고 내부적으로 데이터 저장
**Repository:** 기존 백엔드를 설계해본 경험으로 데이터 로직을 따로 분리해 RoomRepository, ReserverationRepository로 관리함.
